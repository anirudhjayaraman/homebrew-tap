# anirudhjayaraman/tap

Homebrew formulae by Anirudh Jayaraman.

## macverdict

[macverdict](https://github.com/anirudhjayaraman/macverdict) tells you why your Mac was slow this week
and what to do about it: slowdown blame, a RAM verdict, a battery forecast and MacBook Air
throttling, from quiet background sampling.

```bash
brew install anirudhjayaraman/tap/macverdict
macverdict setup
```

To remove it: `macverdict uninstall`, then `brew uninstall macverdict`.

macverdict was called macpulse until 0.2.0; `brew upgrade` moves existing installs over.
