# anirudhjayaraman/tap

Homebrew formulae by Anirudh Jayaraman.

## macpulse

[macpulse](https://github.com/anirudhjayaraman/macpulse) tells you why your Mac was slow this week
and what to do about it: slowdown blame, a RAM verdict, a battery forecast and MacBook Air
throttling, from quiet background sampling.

```bash
brew install anirudhjayaraman/tap/macpulse
macpulse setup
```

To remove it: `macpulse uninstall`, then `brew uninstall macpulse`.
